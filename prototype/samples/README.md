# prototype/samples/ — 模拟样例数据

本目录是原型的**测试与演示素材**。竞赛要求「作品可以使用模拟数据，但应说明数据来源、模拟条件等」，以下内容即为该说明的依据。

## 数据来源

**全部虚构**。三份样例均为编写者依据校园常见场景自行撰写的合成文本，**不对应任何真实单位、真实通知、真实个人**。文中出现的单位、地点、日期、联系方式均为编造。

- 不包含任何真实姓名、学号、手机号、邮箱
- 不包含任何真实的班级、学院内部事务
- 不包含任何真实第三方通知的原文

## 模拟条件

| 文件 | 模拟场景 | 用于验证 |
| --- | --- | --- |
| `notice-internship.txt` | 某学院通知：毕业实习材料提交 | 明确截止时间、明确交件地点 → 应全部抽取为**高置信度** |
| `notice-exam-week.txt` | 某学院通知：考试周安排 | 含模糊时间（「本周内」「下周一之前」）与多处截止时间 → 应触发**低置信度标黄 + 撞期冲突检测** |
| `notice-competition.docx` | 某赛事报名通知 | `.docx` 解析路径（zip + `word/document.xml`），验证不依赖任何库的解压实现 |

## 实际应用时仍需解决的问题

如实记录（会写进项目文档，不要删）：

1. **覆盖度有限**：规则式抽取只能命中写法规范的截止时间，真实通知里大量使用「详见附件」「另行通知」等间接表述，需要 AI 抽取补齐。
2. **格式依赖**：`.docx` 解析只覆盖标准 OOXML，扫描版 PDF、图片截图尚不支持。
3. **语义歧义**：「本周内」的绝对日期依赖当前系统时间，跨时区、跨系统日期设置会导致偏差。
4. **冲突判定规则简单**：当前只按日期级别判重与判冲突，未处理同日内不同时段、以及「开始—截止」区间重叠。

## 使用方式

- **页面内一键演示**：内容已内联在 `prototype/index.html` 中，不发起任何网络请求（保证 `file://` 直接打开也能跑）。
- **拖入测试**：本目录的三个文件可用于验证文件输入与 `.docx` 解析路径。把它们拖进原型窗口即可。

> ⚠️ 若日后接入真实素材：**必须先打码**，且未打码原件不得进仓库——`.gitignore` 已排除 `raw/`、`群聊/`、`截图原图/` 等目录。
